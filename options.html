    Helpful, not invisible.

    What it attempts

    • Non-zero measurements for small, empty elements with known adblock-test names.
    • Normal-looking display and visibility values for those same test elements.
    • Optional removal of obvious, short adblock modal messages.

    What it cannot promise

    • Bypassing blocked-request, script-load, iframe or server-side checks.
    • Hiding the extension or its JavaScript changes from a determined website.
    • Auto-recognising the "real" download button vs ad buttons — use uBlock's ad filters; no extension can guarantee 0 fake links.
    • Restoring withheld video/content, or bypassing login, subscriptions or paywalls.
    Troubleshooting & technical limits

    If a page breaks, use Turn off & reload. If the popup cannot open, disable QuietBlock in the browser's extensions page and reload the affected tab. Turning a script off does not undo changes inside an already-loaded page until that page reloads.

    Protection starts at document_start in the top-level page only. It is intentionally narrow: normal page elements, large inline-sized ad slots and content-filled elements are left alone. It does not emulate successful ad requests, spoof every DOM API, or guarantee script ordering on every site.

    The experimental cleanup only hides matching modal-like elements; it does not make a detection test pass. It may miss popups, leave backdrops, or incorrectly hide a panel. Likely login, payment and subscription dialogs are deliberately skipped. Browser internal pages, extension stores, built-in PDF viewers, local files and incognito windows are not supported by default.

    Compatibility: Chrome/Chromium-based Edge 120 or newer with unpacked Manifest V3 extensions permitted. Managed/work devices may prohibit Developer mode or unpacked extensions. Keep your existing blocker's filter lists up to date before adding more workarounds.

    Small permissions. Nothing sent away.

    QuietBlock stores enabled hostnames and their per-site settings in local browser extension storage. It reads the current tab's URL when you open its popup. Approved sites allow it to read and modify that page's DOM; optional cleanup inspects matching modal text locally. contextMenus adds "Save image with QuietBlock" on enabled sites; downloads is used only when you long-press or right-click an image — no background/automatic downloads. No accounts, analytics, remote code, cookies API or browsing-history API. This version makes no network requests of its own. Removing a saved site also revokes its optional website permission.
